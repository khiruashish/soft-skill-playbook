# Soft Skill Playbook — lesson videos

This orphan branch holds only the narrated MP4s (one per lesson), so `main` and the GitHub Pages site stay
small. The site streams them from `https://raw.githubusercontent.com/khiruashish/soft-skill-playbook/videos/<lesson path>.mp4`.
Captions, posters and `manifest.json` live on the docs branch under `docs/videos/`.
