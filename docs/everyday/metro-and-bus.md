# Metro & Bus

<div class="ssp-banner" markdown>
**Today's goal:** buy tickets or cards, find the right route, ask where to get off, and handle crowded
or confusing rides on the metro and city buses.
</div>

## Key words

| Word / phrase | Meaning |
|---|---|
| smart card / travel card | a card you top up and tap at the gate |
| top up / recharge | add money to the card |
| token / single-journey ticket | one-time ticket |
| line (Purple Line, Line 2) | a metro route |
| interchange / change at… | station where you switch lines |
| towards / direction | which way the train is going ("towards Whitefield") |
| platform / gate / exit | where you board / enter / leave |
| bus stop / bus stand / depot | where buses stop / start |
| route number | the bus number (e.g. 500D) |
| conductor | person who sells tickets on the bus |
| pass (daily / monthly) | unlimited travel for a period |
| rush hour / peak hours | busiest times |

## Questions you'll ask

=== "Metro"

    - How much is a ticket to MG Road?
    - Can I **top up** my card here?
    - **Which line** goes to the airport?
    - **Do I need to change** trains? **Where** do I change?
    - **Which platform** for trains towards Whitefield?
    - **How many stops** is it to Indiranagar?
    - **Which exit** is closest to the bus stand?
    - **What time is the last train** tonight?

=== "Bus"

    - **Does this bus go to** the railway station?
    - **Which bus** should I take for Koramangala?
    - **How often** does the 500D come?
    - **How much is the fare** to Silk Board?
    - **Could you tell me when we get to** the hospital stop?
    - **Is this the right stop** for the airport bus?
    - **Where should I get off** for the market?

## Questions you'll be asked

| They ask | You answer |
|---|---|
| Where to? | MG Road, please. One ticket. |
| Single or return? | Single, please. |
| Do you have a card? | Yes, I'd like to top it up with ₹500. |
| Do you have change? | Sorry, I only have a ₹500 note. Can I pay by UPI? |
| Ticket? (conductor) | Here's my pass. / One to Majestic, please. |

## Conversation 1: at the metro ticket counter

```dialogue
You: Hi. I'd like a ticket to Cubbon Park, please.
Clerk: Single journey?
You: Yes. Actually, I'll be travelling every day. Can I get a smart card instead?
Clerk: Sure. The card is ₹50, and you can add any amount.
You: Great. Please add ₹500. Can I pay by UPI?
Clerk: Yes, scan here.
You: Done. Which platform should I go to for Cubbon Park?
Clerk: Platform 1, towards Challaghatta. It's four stops.
You: Do I need to change trains?
Clerk: No, it's direct.
You: Thank you!
```

## Conversation 2: on the bus, not sure where to get off

```dialogue
You: Excuse me, does this bus go to St. John's Hospital?
Conductor: Yes. Ticket?
You: One to St. John's, please. How much is it?
Conductor: ₹25.
You: Here you go. Could you tell me when we get there? I'm not from this area.
Conductor: Okay, it's about fifteen minutes.
(Twenty minutes later)
You: Excuse me, have we passed the hospital stop?
Passenger: No, it's the next one, after the signal.
You: Thank you so much!
Conductor: Hospital stop! Get down here.
You: Thanks!
```

## When things go wrong

- "The **gate isn't opening**. My card has balance. Could you check it?"
- "I **tapped in** but forgot to **tap out**. What should I do?"
- "I **took the wrong direction**. How do I go back to Majestic?"
- "Sorry, **is anyone sitting here**?" / "Could you **move in a little**, please?"
- "Excuse me, **I need to get off** at the next stop."
