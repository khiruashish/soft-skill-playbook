## Key words

| Word / phrase | Meaning |
|---|---|
| parcel / package / envelope | what you send |
| speed post / registered post / courier | delivery services |
| sender / recipient / address / PIN code | who sends / who receives / where |
| tracking number / consignment number | number to follow the parcel |
| fragile | breaks easily |
| proof of delivery | signature/photo showing it was delivered |
| return to sender | sent back |
| pickup | the courier collects from your home |

## Questions you'll ask

- **How much does it cost to send** this parcel to Kolkata?
- **How long will it take** to arrive?
- **Is there a faster option?**
- **Do I need to fill in a form?**
- **Can I track it** online?
- **Can you mark it as fragile?**
- **Do you offer home pickup?**
- **What's the maximum weight?**

## Questions you'll be asked

| They ask | You answer |
|---|---|
| What's inside? | Documents. / Some books and clothes. / A laptop charger. |
| Domestic or international? | Domestic, to Kolkata. |
| Does it have any liquids or batteries? | No. / Yes, a small power bank. |
| Do you want insurance? | How much does it cost? / No, thank you. |

## Conversation 1: sending a parcel

```dialogue
Clerk: Next, please.
You: Hi. I'd like to send this parcel to Kolkata.
Clerk: What's inside?
You: Some books and a few clothes. Nothing fragile.
Clerk: Okay, let me weigh it. It's 2.3 kilos. Speed post or ordinary?
You: How long does each one take?
Clerk: Speed post takes three to four days. Ordinary takes about a week.
You: Speed post, please. How much is it?
Clerk: ₹310. Please fill in the recipient's address and PIN code here.
You: Done. Can I track it online?
Clerk: Yes, the tracking number is on your receipt.
You: Thank you.
```

## Conversation 2: missing delivery

```dialogue
Agent: Thank you for calling QuickShip. How can I help?
You: Hi. My parcel shows "delivered", but I haven't received it. The tracking number is QS4471092.
Agent: Let me check… It says it was delivered yesterday at 4:15 pm and received by "security".
You: I checked with our security. They don't have it.
Agent: I'm sorry. Is there a photo or a signature?
You: That's what I'd like to know. Could you send me the proof of delivery?
Agent: I'll raise a complaint with the delivery hub. You'll get an update within 48 hours.
You: Could I have the complaint number, please?
Agent: It's C-88213.
You: Thank you. If it isn't found, I'd like a full refund or a replacement.
Agent: Noted. We'll call you back.
```

## When things go wrong

- "**The parcel arrived damaged.** The box was open."
- "**It's been ten days**, and the tracking hasn't changed."
- "**The address on the label is wrong.** Can I change it?"
- "**The delivery person didn't call** before coming."
