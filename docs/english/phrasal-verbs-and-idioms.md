# Phrasal Verbs & Idioms

<div class="ssp-banner" markdown>
**Today's goal:** understand and use the phrasal verbs and idioms that native speakers and global
colleagues use all the time ("follow up", "sort out", "on the same page") so you understand meetings
better and sound more natural.
</div>

## What is a phrasal verb?

<div class="ssp-formula">verb + <em>small word (up, out, off, on, back…)</em> = a new meaning</div>

**look** = see · **look into** = investigate · **look forward to** = be excited about · **look up** = search for

## 30 phrasal verbs for work and daily life

| Phrasal verb | Meaning | Example |
|---|---|---|
| follow up (on) | check again later | I'll **follow up** with the vendor tomorrow. |
| look into | investigate | Could you **look into** the login bug? |
| sort out | fix, solve | We need to **sort out** the access issue. |
| figure out | understand, find the answer | I can't **figure out** why the test fails. |
| come up with | think of (an idea) | She **came up with** a better design. |
| bring up | mention a topic | Can I **bring up** one more point? |
| point out | draw attention to | He **pointed out** a security risk. |
| set up | arrange, configure | Let's **set up** a call. / I **set up** the server. |
| carry out | do, perform | We **carried out** load tests last week. |
| roll out / roll back | release gradually / undo a release | We'll **roll out** to 10% first. We **rolled back** the update. |
| put off | postpone | Let's **put off** the meeting until Monday. |
| call off | cancel | They **called off** the offsite. |
| catch up (with) | talk to get updated | Let's **catch up** after lunch. |
| fill in (for) | replace someone temporarily | Can you **fill in for** me at stand-up? |
| fill out / fill in | complete a form | Please **fill out** this form. |
| get back to | reply later | I'll **get back to** you by Friday. |
| hand over | give responsibility to | I'll **hand over** my tasks before leave. |
| take over | take responsibility from | Ravi will **take over** the project. |
| run into | meet a problem / person by chance | We **ran into** a memory issue. |
| run out of | have no more | We've **run out of** time. |
| back up | copy data / support someone | **Back up** the database. My manager **backed** me **up**. |
| go over | review | Let's **go over** the plan once more. |
| work out | solve; exercise | It'll **work out**. / I **work out** at the gym. |
| turn down | refuse; lower volume | She **turned down** the offer. |
| show up | arrive | Only five people **showed up**. |
| drop by | visit briefly | I'll **drop by** your desk. |
| log in / log out | sign in / sign out | I can't **log in**. |
| pick up | collect; learn quickly | I'll **pick** you **up** at 8. She **picked up** Kotlin fast. |
| check in / check out | arrive & register / leave (hotel) | We **checked in** at noon. |
| find out | discover | I'll **find out** and let you know. |

## 20 idioms you'll hear at work

| Idiom | Meaning |
|---|---|
| on the same page | agreeing / understanding the same thing |
| touch base | have a short conversation to update |
| ballpark figure | rough estimate |
| low-hanging fruit | easy wins |
| the ball is in your court | it's your turn to decide/act |
| back to square one | start again from the beginning |
| a heads-up | early warning |
| in the loop / keep me posted | informed / keep me updated |
| hit the ground running | start working fast and well |
| cut corners | do it badly to save time |
| get the ball rolling | start something |
| think outside the box | think creatively |
| on the back burner | low priority for now |
| move the needle | make a real difference |
| bite the bullet | do something hard you've been avoiding |
| a win-win | good for both sides |
| take it offline | discuss later, separately |
| bandwidth | time/capacity ("I don't have bandwidth this week") |
| a quick win | a small success that comes fast |
| crunch time | the busy, stressful period before a deadline |

!!! tip "Understand many, use a few"
    You don't need to use idioms to sound professional. **Understand** them when others use them, and
    use only the ones you're comfortable with. With mixed international audiences, plain English is
    clearer.

## Conversation: a quick sync

```dialogue
Manager: Quick heads-up: the client wants to roll out the new app next Monday.
You: That's earlier than planned. Are we all on the same page about the scope?
Manager: Mostly. Can you look into the payment issue Meena brought up yesterday?
You: Sure. I ran into it last week too. I think I can sort it out by Wednesday.
Manager: Great. If it takes longer, give me a heads-up so I can keep the client in the loop.
You: Will do. Should we put off the analytics feature?
Manager: Yes, let's put it on the back burner for now.
You: Okay. I'll follow up with Meena and get back to you this afternoon.
```
