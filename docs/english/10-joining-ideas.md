# Joining Ideas & Opinions

<div class="ssp-banner" markdown>
**Today's goal:** join short sentences into longer, natural ones, give reasons, and share, agree with
or disagree with an opinion.
</div>

## Linking words

| Word | Job | Example |
|---|---|---|
| **and** | add | I booked the tickets **and** paid online. |
| **but** | contrast | The hotel was nice, **but** the food was average. |
| **because** | reason | I was late **because** the metro stopped. |
| **so** | result | The metro stopped, **so** I was late. |
| **or** | choice | We can take a cab **or** walk. |
| **if** | condition | **If** it rains, we'll stay home. |
| **when** | time | **When** I reach the station, I'll call you. |
| **although / even though** | surprising contrast | **Although** it was expensive, it was worth it. |
| **also / too** | add | I **also** need a receipt. / I need a receipt **too**. |
| **however** | contrast (formal, new sentence) | The plan is good. **However**, it's risky. |
| **for example** | example | We need better tests, **for example** for the payment flow. |

!!! warning "Don't double up"
    ❌ *Although it was late, but I went.* → ✅ **Although it was late, I went.** or ✅ **It was late, but I went.**
    ❌ *Because I was sick, so I didn't come.* → ✅ **Because I was sick, I didn't come.**

## if sentences (conditions)

| Type | Pattern | Example |
|---|---|---|
| Real / likely | If + present, will + verb | If the train is late, I'll take a cab. |
| Always true | If + present, present | If you press this, the light turns on. |
| Imaginary | If + past, would + verb | If I had more time, I would learn French. |

## Giving opinions

| Opinion | Agree | Disagree (politely) |
|---|---|---|
| I think… | I agree. / Exactly! / That's true. | I'm not sure about that. |
| In my opinion… | I feel the same way. | I see it a bit differently. |
| I feel that… | You're right. | That's a good point, but… |
| If you ask me… | Absolutely. | I agree up to a point, but… |
| I'd say… | Good point. | I'm afraid I don't agree, because… |

**Give a reason:** "I think we should take the train, **because** it's faster than the bus **and** we can
work on the way."

## Conversation: deciding where to eat

```dialogue
Colleague: Where should we go for the team lunch?
You: I think we should try the new Andhra place, because everyone likes spicy food.
Colleague: That's true, but it's a bit far. It takes twenty minutes to get there.
You: Good point. If we leave at 12:30, we'll be back by 2. Although it's far, the food is really good.
Colleague: Hmm. What about the vegetarians?
You: They have a big vegetarian menu too, so it should be fine.
Colleague: Okay, I agree. Let's book a table for ten.
You: Great. I'll call them now and book it.
```

## Practice

**1. Join with and, but, because, so.**

1. It was raining. I took an umbrella. 2. I like my job. It's very stressful. 3. I was tired. I went to bed early.

??? success "Answers"
    1. It was raining, so I took an umbrella. 2. I like my job, but it's very stressful.
    3. I went to bed early because I was tired. (or: I was tired, so I went to bed early.)

**2. Complete.** If the flight is cancelled, ______. / If I had a car, ______.

??? success "Sample answers"
    …I'll book a train ticket. / …I would drive to work.

**3. Give your opinion with a reason:** "Is working from home better than working in the office?"
